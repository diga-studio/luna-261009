# UnifiedDataForge — 精确模糊实体聚类库

TypeScript 实现。输入至多 10000 条记录（`id` / `title` / `address` / `lat` / `lon`），
提供 `isDuplicate(a, b)` 与 `cluster(records)` 两个操作。

## 构建与测试

```sh
npm install
npm test        # tsc 编译 + node --test
```

只依赖 `typescript` 与 `@types/node`（均为 devDependencies），运行时零依赖。

## 直接重复的判定

同时满足：

1. 标题相似度 ≥ 85%：`20·d ≤ 3·L`（整数运算，严格等价），`d` 为码点级
   Levenshtein 距离（增/删/改代价均为 1），`L` 为两串最大码点长度；
2. 地址相似度 ≥ 85%：同上；
3. 球面距离 ≤ 100 m：半径 6371000 m 球体上的最短大圆弧（haversine）。

相似度比较前依次做：NFKC → `toLowerCase` → 连续 ASCII 空格折成一个 → 去除首尾
ASCII 空格（只处理 U+0020）。

`cluster` 返回直接重复关系的**连通分量**（并查集），单例保留；输出按 id 排序，
与输入顺序无关。`distanceEvaluations` 统计本次 `cluster` 实际发起的全部编辑距离
计算（含提前退出的计算；索引构建不做任何编辑距离计算）。

## 候选缩减为何不漏对

不枚举全部记录对、不物化距离矩阵。候选生成是必要条件过滤，每一级都可证明无损：

1. **鸽巢分片（标题）**：重复对的编辑距离 `d ≤ ⌊3L/20⌋ ≤ ⌊3·64/20⌋ = 9`。
   把每条记录的规范化标题切成 10 = 9+1 个连续片段，每次编辑至多破坏一个片段，
   故重复对至少有一个片段原样出现在另一串中。索引为 `片段串 → 记录列表`；
   新记录用自身标题的所有长度 1–7 子串探测（7 = ⌈64/10⌉ 为最大片段长），
   因此任何重复对必然成为候选。位置窗口 `|片段起点 − 命中起点| ≤ 9` 也是无损的：
   完好片段在另一串中的位移不超过它之前的净增删数，而净增删数 ≤ d ≤ 9。
   短于 10 码点的标题产生空片段，空片段是任何串的子串，单独按同一位置窗口处理。
2. **长度过滤**：重复对必要满足 `|lenA − lenB| ≤ ⌊3·max(lenA,lenB)/20⌋`。
3. **地理过滤**：haversine 不是编辑距离计算，先于标题/地址比较执行。
4. **连通分量跳过**：若两记录已在同一并查集分量中，二者之间再加边不会改变
   最终划分，故跳过且不产生任何评估。这不是"只比较簇代表"——每个可能改变
   划分的对都会被精确评估。

通过全部过滤的对再按定义精确计算标题、地址相似度（带阈值提前退出的 Levenshtein）。

## 退化情况

- **大量记录共享标题片段**（如标题全相同）：候选对数退化为这些记录的全组合。
  实现按流式处理候选（不物化对列表），配合连通分量跳过，`distanceEvaluations`
  仍接近线性；但候选生成的 CPU 开销本身可能接近 O(n²)。
- **大量短标题（< 10 码点）**：空片段使候选变多，长度过滤会挡掉大部分；
  极端时同样退化为近 O(n²) 候选。
- **10000 条密集数据**（1000 组 × 10 条、同地址同坐标）：实测
  `distanceEvaluations ≈ 1.8 万`，远低于 20 万上限，单次 `cluster` 约 0.75 s。

## 目录结构

- `src/normalize.ts` — 规范化管线
- `src/levenshtein.ts` — 码点级 Levenshtein（阈值提前退出）
- `src/geo.ts` — haversine 球面距离
- `src/cluster.ts` — `isDuplicate` / `cluster`（候选索引 + 并查集）
- `test/` — 单元测试、对照穷举的小数据测试、1000 组密集数据测试
