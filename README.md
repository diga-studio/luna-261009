# live-exposure-stats

直播出镜曝光统计库。载入一场活动的完整配置、活动时长、初始状态和导播操作记录后，
可查询任意回放区间内每路输入的有效出镜毫秒。配置、回放记录和统计数据全部保存在
进程内，不处理视频内容。

## 构建与测试

```sh
npm install
npm test        # 编译 TypeScript 并运行全部测试
npm run build   # 仅编译到 dist/
```

仅依赖 Node.js 与开发依赖 typescript（含 @types/node），无运行时依赖。

## 使用

```ts
import { ExposureTracker } from "live-exposure-stats";

const tracker = new ExposureTracker(config, operations);
const result = tracker.query(60_000, 120_000); // 左闭右开
for (const [inputId, ms] of result) {
  console.log(inputId, ms); // 该路输入在区间内的有效出镜毫秒
}
```

## 模型说明

- 坐标与尺寸为整数万分比，`10000` 为画布一整边；矩形允许超出画布，超出部分裁掉，
  按连续平面实际面积计算，与输出分辨率无关。
- 槽位属于场景，同一路输入可绑定多个槽位；`z` 较大者在上，`z` 相同时配置靠后者在上。
  槽位画面完全不透明；只有 `active` 状态的输入参与画面，`standby`/`disabled`
  与隐藏槽位既不贡献面积也不遮挡下方。
- 矩形叠层位于所有槽位之上，不透明度 0~1 且在矩形内均匀；隐藏叠层不遮挡。
  某点剩余画面系数为覆盖该点的所有可见叠层 `1 - opacity` 的乘积。
- 导播操作（切场景 / 改输入状态 / 改叠层显隐）瞬时生效；同一时间戳按记录顺序
  全部应用后进入下一段时间，最后的状态持续到活动结束。
- 每个时刻画布上某点由最上方有效槽位决定归属；同一路输入多个槽位的重叠部分
  只计算一次。有效出镜毫秒 = 贡献面积占画布面积的比例 × 时间，按区间累加。
- 查询顺序不影响结果；相邻区间结果之和等于合并区间结果。

## 实现要点

- `src/timeline.ts`：把操作记录折叠为状态恒定的时间分段（左闭右开）。
- `src/geometry.ts`：将槽位与叠层的边投影到两轴，把画布切分为基本单元格；
  每个单元格内最上方槽位与叠层集合恒定，贡献可精确求出并累加到对应输入。
- `src/tracker.ts`：对外入口，按查询区间与各分段的交集累加有效出镜毫秒，
  面积占比按分段状态缓存。
